# Spots App

The **Spots App** is an interactive web application built as part of the **TripleTen Software Engineering Program**. It demonstrates modern frontend development practices, user experience design, and API integration through a responsive, dynamic photo-sharing platform.

---

## Features

### Core Functionality
- **User Profile Management**
  - Edit profile name and description
  - Change profile avatar with image URL
  - Display user information dynamically

- **Photo/Card Management**
  - Create new posts with image URL and caption
  - Delete posts with confirmation modal
  - Like/unlike posts with toggle functionality
  - View full-size image preview

- **Modal System**
  - Edit Profile modal
  - New Post modal
  - Edit Avatar modal
  - Image Preview modal
  - Delete Confirmation modal

- **Form Validation (Stage 9 focus)**
  - Real-time input validation
  - Error message display
  - Submit button state management
  - Required field validation
  - URL format validation
  - Text length validation (min/max characters)

- **User Experience Enhancements**
  - Smooth modal transitions
  - Keyboard navigation (ESC key to close)
  - Click outside modal to close
  - Loading states ("Saving..." text)
  - Form reset after submission
